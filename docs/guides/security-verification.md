# 安全验证（Step-up）

> 相关：[账号认证](certification.md) · [账号 API](../api/accounts.md) · [ADR-0026](../adr/0026-stepup-verification.md)

「安全验证」用于敏感操作前的**本人确认**。它与**认证**正交：认证回答「账号是不是可信社员」（入社时、多条通道、有有效期）；安全验证回答「现在这个操作是不是本人」（每次危险操作、通过一次管 10 分钟）。

## 什么时候会碰到

| 操作 | 要求 |
|---|---|
| 修改密码 | 原密码 ＋ 安全验证（两个都要） |
| 换绑邮箱 | 安全验证（**首次绑定邮箱不拦**） |
| 设置 / 更换 / 清除安全问题 | 首次设置＝重输登录密码；更换与清除＝安全验证 |

被拦截时前端会跳 `/#/verify?action=…&next=…`；完成验证后自动回到原操作——**再点一次原按钮重试即可**（10 分钟内同一操作免复验）。

## 两种方式

- **邮箱验证码**：发到**已认证邮箱**（未认证邮箱不可用——先去「账号认证」完成邮箱认证）。6 位数字、10 分钟有效、最多试 5 次、60 秒可重发一次，每小时有上限。
- **安全问题**：从预设题库（10 题）中自选 1–3 题作答；验证时随机抽 1 题。答案不区分大小写与全半角（按此归一化比对）。

## 设置与记录

个人中心 →「**安全验证**」：查看方式状态、设置 / 更换 / 清除安全问题、查看最近验证记录。

- **首次设置安全问题需输入登录密码**——防止「只偷到会话、没有密码」的人给自己加验证方式再改密码；
- 答案只存哈希，保存后不再显示；管理员也无法在后台看到答案明文。

## 走不通怎么办

- 邮箱方式不可用 → 先完成邮箱认证，或改用安全问题；
- 两个方式都不可用 → 设置安全问题（需登录密码）；仍走不通 → 联系信息组协助处理。
